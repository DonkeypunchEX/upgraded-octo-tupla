# 🧠 Tulpa AI Assistant – Raspberry Pi Edition

A fully-local, offline AI assistant that runs on Raspberry Pi 5, fine-tuned on your personal knowledge base ("protocols") and designed to emulate expert consultation in cognitive enhancement, longevity, and gnosis domains.

---

✨ Features

· Fully Offline Operation – No internet required after setup
· Personalized Knowledge Base – RAG system trained on your own protocols/exports
· Voice Interface – Wake-word detection, speech-to-text, and text-to-speech
· Optimized for RPi5 – Runs efficiently on 5W power, minimal memory footprint
· Multi-Modal Access – Web dashboard, API endpoints, and voice interaction
· Continuous Learning – Automatically processes new protocol exports
· Production Ready – Systemd service, health monitoring, automatic recovery

---

📋 Prerequisites

Hardware

· Raspberry Pi 5 (4GB/8GB recommended)
· MicroSD card (32GB+)
· Power supply (5V/5A recommended)
· Optional: USB microphone, speaker for voice mode

Software

· Raspberry Pi OS 64-bit (Bookworm)
· Python 3.9+
· Ollama 0.5+
· 5GB free storage for models and data
